# Імітація TLS / SSL рукостискання та захищена передача даних (All-to-One)

Цей проєкт є практичною реалізацією розрахунково-графічної роботи з дисципліни "Безпека програмного забезпечення". Програма імітує процес встановлення захищеного з'єднання (TLS-рукостискання) між клієнтом та сервером, а також реалізує безпечну багатопотокову передачу 3D-мешів.

## Опис роботи

Проєкт демонструє використання криптографічних примітивів для створення безпечного каналу зв'язку поверх стандартних TCP-сокетів. Робота складається з двох основних етапів:

1. **Криптографічне рукостискання (TLS Handshake):**
   - Клієнт та сервер обмінюються випадковими рядками (`client_random`, `server_random`).
   - Сервер надсилає свій публічний RSA-ключ.
   - Клієнт генерує секрет `premaster_secret`, шифрує його публічним ключем сервера та надсилає.
   - Обидві сторони незалежно генерують симетричний сеансовий ключ (Session Key) за допомогою хешування (SHA-256).
   - Сторони обмінюються зашифрованими повідомленнями "READY" для підтвердження успішності рукостискання.

2. **Захищена передача даних (All-to-One 3D Mesh Transfer):**
   - Після встановлення сеансового ключа всі подальші комунікації шифруються за допомогою симетричного алгоритму **AES-GCM**.
   - Сервер реалізовано з використанням багатопотоковості, що дозволяє йому одночасно приймати підключення та файли (3D-меші у форматі `.obj`) від багатьох клієнтів (режим All-to-One).
   - Клієнт автоматично генерує тестовий 3D-меш (куб), шифрує його та відправляє на сервер.

## Структура проєкту

- `crypto_utils.py` - модуль з усіма криптографічними функціями (генерація RSA-ключів, шифрування/розшифрування RSA, генерація сеансового ключа, AES-GCM шифрування);
- `server.py` - TCP-сервер, який прослуховує вхідні з'єднання, виконує рукостискання та зберігає отримані зашифровані файли;
- `client.py` - TCP-клієнт, який ініціює з'єднання, проводить рукостискання, генерує тестовий 3D-меш та відправляє його серверу;
- `requirements.txt` - список залежностей проєкту;
- `data_to_send/` - директорія, де клієнт створює файли для відправки (ігнорується git);
- `received_data/` - директорія, куди сервер зберігає розшифровані файли від клієнтів (ігнорується git).

## Як запустити

1. Переконайтеся, що у вас встановлено Python.
2. Встановіть необхідні залежності:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустіть сервер:
   ```Bash
   python .\src\server.py
   ```
   
4. У новому вікні термінала запустіть клієнт:

    ```Bash
    python .\src\client.py
    ```
   
5. Для перевірки режиму All-to-One ви можете запустити кілька екземплярів клієнта одночасно, поки працює сервер.
